Ω-BMS is my extension of Bashicu Matrix System to transfinitely many rows, and denoted as α-BMS, where α is an ordinal. I designed it so for finite N, N-BMS is equivalent to N-row BMS, and the smallest matrix in ω-BMS gives the ordinal Lim(BMS).

Bashicu Matrix System is a matrix system made by Bashicu. Examples inlcude:

Analysis beyond (0,0,0)(1,1,1) is an open problem. Also, from now on, I'll omit unnecessary 0s.

The Limit of BMS can't really be written in any other way besides Lim(BMS). It's fundamental sequence is (), (0)(1), (0)(1,1), (0)(1,1,1), ...
If I notate N 1s as 1N, then we obtain the following fundamental sequence; (), (0)(1), (0)(12), (0)(13), (0)(14), ... which I can simplify to Lim(BMS)[N] = (0)(1N).
If I define (0)(1α)[N] as (0)(1α[N]) for a limit ordinal α, then (0)(1ω) is exactly Lim(BMS).
I can also define (0)(1α+1)[N] as (0)(1α)(2α)...(Nα), which means that (0)(1α+1) = Lim(α-BMS).
Those are the only two new rules, otherwise it expands like BMS.
