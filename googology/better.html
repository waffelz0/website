Better Array Notation

(This page does not serve as an introduction to the notation. It just hosts its definition.)
Better array notation (BAN) is the sequel to my Boring array notation. It is the collective name of multuple parts (currently 2):

Name Limit Ordinal
Simple Better Array Notation (SBAN) ε0
Nested Better Array Notation (NBAN) ψ0(Ω2)

Better array notation is further split into linear BAN (identical to Chris Bird's and Jonathan Bowers' linear arrays), dimensional BAN, and hyperdimensional BAN.

Before describing its rules, I'm going to describe a few terms I'll be using.
The pilot is the array's first element, and the copilot is the array's second element. All valid arrays must have both a pilot and copilot.
The prime is the first non-1 element after the copilot. The coprime is the element directly before the prime. The coprime does not exist if the prime is the third element.

Simple Better Array Notation

Limit ordinal: ε0

Rules

Let @ be a string of numbers separated by arbitary separators or arrays.
Let p, c, a, and b be the pilot, copilot, and prime, and coprime respectively.
Rule 1. [p,c] = p^c
    If the array has two elements, the result is the pilot raised to the power of the copilot.
Rule 2. [@,1] = [@]
    If the array ends with 1, it can be removed.
Rule 2. [p,1,@] = p
    If the copilot is 1, the result is the pilot.
Rule 4. [p,c,1...1,a,@] = [p,p,p...p,[p,c-1,1...1,a,@],a-1,@]
    If the third element is 1, and 1...1 is an unbroken string of 1s, replace every element before the coprime with the pilot, replace the coprime with a copy of the array with the copilot decreased by 1, and decrement the prime by 1.
Let (0) be a comma, A, B be separators, Anx be x n's separated by A's, and nx be x n's separated by commas.
Let C be an arbitrary string of numbers, and C' be the expanded version of C with respect to the pilot and copilot. Rules are applied to the first non-1 entry.
Rule 5. If A<B, [p,c A 1 B @] = [p,c B @]
Rule 6. [p,c(N,@)n,@] = [p,p(N-1,@)pc(N-1,@)2(N,@)n-1,@]
Rule 7. [p,c(1x,m,@)@] = [p,c(px,m-1,@)@]
Rule 8. (...(C)...) = (...(C')...)

Notes

Arrays whose separators are all less than (1) are called linear arrays.
Arrays whose separators are all less than (1,2) are called dimensional arrays.
All other arrays in SBAN are called multidimensional arrays.

Nested Better Array Notation

HUGE THANKS TO MY FRIEND VEE
Limit ordinal: ψ0(Ω2)

Rules

Let @ be a string of numbers separated by arbitrary separators or arrays.
Let p, c, a, and b be the pilot, copilot, and prime, and coprime respectively.
Let /n represent n /s concatenated. Let X be any valid array. In the separator /nX, X is linked to /n if and only if n>1, and X contains a / separator in the highest level. Separators of the form /n(.../b...) are valid if and only if n>1 and b=1.
Let C be an array, and C' the expanded version of the array with respect to the pilot and copilot.
Rule 1. (.../(#)1/(#)N@) = (.../(#)1(.../(#)1(...(.../(#)N-1@)...)2/(#)N-1@)2/(#)N-1@) (b nests, if linked all nests include the linked part as well)
Rule 2a. (.../(z,@)2) = (.../(z-1,@)1/(z-1,@)...1/(z-1,@)2) (b /(z-1,@)s)
Rule 2b. (.../b(C)...) = (.../b(C')...)
Rule 2c. (.../b(1/2)...) = (1/b-1(1(1/b-1(1(1/b-11(...)2)2)2)2)2) (b nests)
